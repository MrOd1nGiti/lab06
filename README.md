# Лабораторная работа 6. Списки и обработка наборов данных

Выполнил: Вариант 1 (Чётные числа)

## Описание программ

- `statistics.py` - вычисляет статистические показатели списка чисел (количество, сумма, минимум, максимум, среднее) или выводит сообщение об отсутствии данных при пустом вводе.
- `transform.py` - создает независимую копию списка с заменой отрицательных чисел на их модули, сохраняя исходный список неизменным.
- `positions.py` - находит все индексы максимального элемента в списке в порядке возрастания.
- `variant.py` - выбирает из списка чётные числа, выводит их в исходном порядке, считает количество, сумму и формирует отсортированную копию.

## Проверка работы программ

### statistics.py
- Ввод: `-2 0 5 3`
  Вывод:
  Количество: 4
  Сумма: 6
  Минимум: -2
  Максимум: 5
  Среднее: 1.50
- Ввод: `8`
  Вывод:
  Количество: 1

  Минимум: 8
  Максимум: 8
  Среднее: 8.00
- Ввод: `""` (пустой ввод)
  Вывод: Нет данных

### transform.py
- Ввод: `-2 0 5 -2`
  Вывод:
  Исходный список: [-2, 0, 5, -2]
  Новый список: [2, 0, 5, 2]

- Ввод: `7 7`
  Вывод: [0, 1]
- Ввод: `-3 -1 -2`

- Ввод: `""`
  Вывод: Нет данных

## Ответы на вопросы к защите

1. **Сохранение исходного списка во втором задании**: Достигается за счет создания отдельного пустого списка и поэлементного заполнения его новыми данными через `append()`, либо через использование метода `.copy()`. Простое присваивание через `=` связывало бы две переменные с одной ячейкой памяти.
2. **Отличие `append()` от присваивания по индексу**: `append()` добавляет новый элемент в конец списка, увеличивая его длину. Присваивание по индексу (`items[i] = value`) заменяет уже существующий элемент в заранее выделенной ячейке списка и вызывает ошибку IndexError, если индекс выходит за текущие границы.
3. **Отличие `sorted()` от `sort()`**: Функция `sorted(items)` создает и возвращает **новый** отсортированный список, оставляя исходный объект без изменений. Метод `items.sort()` сортирует список **на месте** (меняет порядок элементов в исходном списке) и возвращает `None`.
